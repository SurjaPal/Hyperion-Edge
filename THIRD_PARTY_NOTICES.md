All application code in `backend/`, `dashboard/*.js|css|html`, `ml/`, and `scripts/` is original
work by the submitter. `results/optuna.db` and every file under `results/` and `models/fed_init.npz`
are original outputs generated by running the code in `ml/` against the SKAB dataset -- they contain
no raw sensor readings, only aggregate metrics and trained model weights.
